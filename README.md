# EcoCollect – Waste Collection Scheduling System

EcoCollect is a web-based waste collection scheduling system designed to help residents schedule waste collection and allow administrators to manage collection requests efficiently.

## Features

- Resident waste collection request
- Collection date and time scheduling
- Waste type selection
- Request status tracking
- Admin dashboard
- Pending, approved, and completed request status
- Request management

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

The system was developed to improve the organization and management of waste collection services and make it easier for residents to submit and track collection requests.
